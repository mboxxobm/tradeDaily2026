# トレード日誌の収集データ・構成要件

更新日：2026-11-05（日本時間）
出典：本人がこの会話に提示した日誌作成要件。

**取り込み作業の手順書**：[データ取り込み手順書・要件定義](requirements/TRADE_DIARY_DATA_IMPORT_PROCEDURE.md) を参照。これは日誌本文ではなく、CSV・板・歩み値・チャート画像をどう収集・照合・表示するかの手順を定義する。

## 集約するデータ

| 種類 | データソース | 日誌への記録 |
|---|---|---|
| 実取引 | 松井証券のCSV | 注文・約定・決済・数量・損益。CSVにある項目と確認範囲を明記する |
| デモ | TradingViewのペーパートレード | 注文・約定・決済・数量・損益。実取引と区別する |
| 指数 | 日経平均の1分足ソースデータ | トレード前後の値動きと各時点の終値 |
| 個別銘柄の板・歩み値 | 株ステーションや「ブリスケ等」から取得するデータ | 観測時刻、価格、数量、買い支え・売り圧力などの判断理由。「ブリスケ等」の正式なサービス名・形式は未確認 |
| チャート画像 | OneDriveの当日の日付のチャートフォルダ・ファイル | その都度レイアウトしたTradingViewの画面キャプチャ。画像と銘柄・時間足・時刻を対応付ける |

これらは収集対象の指定であり、すべての接続や自動取得が完了したという意味ではない。実行時に参照できるファイル・画像・会話だけを使用し、取得元のファイル名または参照リンクを残す。OneDriveの具体的なパスやアクセス手段は、実際に確認できた情報を使う。

## 最重要の時系列要件

単なる取引一覧にせず、各エントリーの前後が検証できるよう、以下の5時点を網羅する。

| 時点 | 必須の記録 |
|---|---|
| 9時台・ビフォー | スタート状態、環境認識、チャート、終値 |
| エントリー直前 | 直前のチャート・板・歩み値、判断理由、終値 |
| エントリー10分後 | エントリー時刻を基準とした10分後の状況、チャート、終値 |
| 前引け・11:30 | 前場終了時点の表示、チャート、終値 |
| 大引け・15:30 | 最終の引けの表示、チャート、終値 |

- 時刻は日本時間を基準にし、元データのタイムゾーンが異なる場合は変換元も記録する。
- 終値には対象銘柄、時間足、足の時刻、データソースを併記する。日経平均、日経225先物、JP225 CFDなどは実際のデータ系列名を明記し、同じ価格系列として混ぜない。
- エントリー直前の判断には、その時点までに確定していた足の終値を使う。進行中の足を使う場合は未確定と明記し、後から確定した終値を当時既知だった値として扱わない。
- 板・歩み値そのものに終値はないため、同時点のチャート・足データと関連付ける。画像だけで判読できない価格を推測しない。
- 画像の撮影時刻と表示されている足の時刻を区別する。後から取得した画像は事後資料と明記する。
- データがない時点も行を残して「未取得」「未確認」と記載する。エントリー10分後が休場中などの場合はその状況を明記し、別時刻の値を同時点の終値として代用しない。
- 11:30・15:30の表示要件は日本株の日誌の基準。NY取引などへ適用する場合も実際の市場・セッションを明記し、米国市場の引けとして扱わない。

## 記録の扱い・適用範囲

- 実取引、デモ、未実行案、本人申告、CSV等で確認済みの値を区別する。
- 不確かな価格・株数・ロット換算・損益を補完しない。本人の口述とCSVに差があれば、出典と差分を残して照合する。
- 判断理由、結果、反省・検証課題を分ける。後からの値動きをエントリー時の根拠に混ぜない。
- 新しい実況・取引・検証記録がない日は、この表だけの空の日誌を作らない。
- 今後の日誌作成・追記で適用する。既存の日誌は保持し、過去の欠けたデータは参照できる資料が得られた範囲で補足する。
- 本ファイルは要件メモ。収集スクリプトやOneDriveとの自動連携を実装したものではない。

## 日経平均の定型分析テンプレート

追加日：2026-11-05（JST）。本人が日々分析し、音声で読み上げる固定項目。

| 分析項目 | 設定・色 |
|---|---|
| 週足の移動平均 | 20 SMA・白色 |
| 日足の移動平均 | 20 SMA・赤色 |
| 60分足の移動平均 | 20 SMA・黄色 |
| 5分足の移動平均 | 60 EMA・緑色 |
| Open | 日本時間9:00の価格 |
| Williams %R | 60分足・期間15 |

日誌の環境認識に次の記入欄を使う。方向や値は本人申告・確認できた資料を転記し、未提示の結果を補わない。

| 項目 | 値・価格との位置関係／向き | 基準時刻・足の確定状態 | 出典 |
|---|---|---|---|
| 対象銘柄・配信系列 | 未確認 | 観測時刻JST：未確認 | 未取得 |
| 週足20 SMA（白） | 値・価格の上下・MAの向き：未確認 | 未確認 | 未取得 |
| 日足20 SMA（赤） | 値・価格の上下・MAの向き：未確認 | 未確認 | 未取得 |
| 60分足20 SMA（黄） | 値・価格の上下・MAの向き：未確認 | 未確認 | 未取得 |
| 5分足60 EMA（緑） | 値・価格の上下・MAの向き：未確認 | 未確認 | 未取得 |
| 9:00 Open（JST） | 価格・現在価格との上下：未確認 | 当日9:00 | 未取得 |
| 60分足Williams %R（15） | 値・向き・位置：未確認 | 未確認 | 未取得 |
| 本人の総合判断 | 上／下／レンジ・条件：未確認 | 未確認 | 未取得 |

- SMAとEMA、時間足と期間を区別する。％Rは**60分足の期間15**。15分足へ読み替えない。
- 9:00 Openは当日9:00の価格として記録し、ローソク足終値や他市場のセッション開始価格とは混同しない。実際の始値か9:00時点の観測価格かも、資料に応じて明記する。
- 日経平均現物・先物・CFDの系列、資料時刻・足の確定状態を示す。読み上げ値とCSV確認値は区別し、差があれば両方を残す。
- この定型分析は既存の5時点の記録に関連付ける。テンプレートの追加だけで新しい売買や日誌を作らない。

## 日経平均の分析を引き継ぐ運用（2026-11-05本人指定）
- 週足20SMAの環境認識は週1回の確認を基本とし、同じ週は直近の確認済み記録を引き継ぐ。日足20SMAは日1回の確認を基本とする。前日・前々日等の確認済み日誌を参照し、毎回「未確認」に戻さない。
- 引き継いだ項目には元の確認日・参照日誌と「引き継ぎ」を記し、当日に新規確認した結果と区別する。前の記録が確認できない場合は作らない。新しい読み上げや訂正があれば優先して更新する。
- 週足・日足の分析頻度は本人の確認ルーチンであり、進行中のMAが動かないという意味ではない。60分足20SMA、ボリンジャーバンドの拡大・縮小、5分足60EMA、9:00 Openとの上下、60分足Williams %R（15）は当日の実況に応じて更新する。
- 明確な訂正は追記欄だけでなく、日誌冒頭の定型分析表にも反映し、古い「未確認」や聞き取り保留と矛盾させない。売買記録・原資料は保持する。
- 11月5日の本人確認例：週足20SMA（白）レンジ、日足20SMA（赤）下、60分足20SMA（黄）横・レンジ、BB拡大、5分足60EMA（緑）横、9:00 Openより下、60分足%R（15）下。これは当日の分析であり、将来の日を固定する設定値ではない。
