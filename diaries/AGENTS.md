# 日誌の保存・追記ルール

ユーザー指定（2026-10-26）：毎日の日誌は、このリポジトリの `main` ブランチの `diaries` 配下へ保存・追記する。

- 日付は日本時間（Asia/Tokyo）を基準にする。既存形式 `diaries/YYYY-MM-DD/diary_YYYYMMDD.md` を使う。
- 作業前に対象日の日誌の最新版を取得する。同じ日の日誌があれば内容を保持して、新しい実況・振り返りだけを追記する。なければ作成する。
- 実況、環境認識、売買、判断理由、反省・検証課題を日本語のMarkdownで整理する。ユーザーの訂正を反映し、口述の不明点は未確認として残す。
- 実取引、Paper Trading／デモ、未実行の検討案を区別する。約定履歴で確認した値と本人の申告・概算を区別し、不確かな数量や価格から確定損益を作らない。
- 日経225と個別銘柄のシンクロ、寄り付き回避、デルタ上サイン、「おかしい」時の即撤退、分割利確は、当日の記録がある範囲で整理する。
- 別の会話やローカルファイルを自動取得できるとはみなさない。実際に参照できた記録を使い、記録のない日の取引を作らない。
- 既存の日誌と照合して重複追記を避ける。原資料・CSV・画像は保持する。追記のために過去の日誌や別ファイルを削除・移動しない。
- GitHubへの保存が成功したことを確認してから、更新した日誌へのリンクを伝える。保存失敗を成功として報告しない。

## 収集データ・時系列の追加要件（2026-11-01）

- 日誌作成時には [JOURNAL_REQUIREMENTS.md](JOURNAL_REQUIREMENTS.md) と [データ取り込み手順書](requirements/TRADE_DIARY_DATA_IMPORT_PROCEDURE.md) を読み、松井証券CSV・TradingViewペーパートレード・日経平均1分足・個別銘柄の板と歩み値・OneDriveの当日チャート画像を、実際に参照できる範囲で関連付ける。
- 各取引について、9時台のビフォー、エントリー直前、エントリー10分後、前引け11:30、大引け15:30の5時点を記録する。各時点の終値には銘柄・時間足・足の時刻・確定状態・出典を付け、未取得の資料や価格は推測せず明記する。
- 新しい記録がない日は、テンプレートだけの空の日誌を作らず、変更なしとする。

## 習慣化の振り返り（2026-11-02）

- 本人は、当日使わなくても必要な場面に備えて準備を続けることを、トレード・語学学習などに活かしたいと希望している。今後の振り返りでは、成果に加えて「決めた準備を実行できたか」も、記録のある範囲で確認する。
- 具体的な習慣や達成状況は、本人の発言・資料で確認できたものだけを記録する。参考：[11月2日の本人の方針](2026-11-02/diary_20261102.md)。
