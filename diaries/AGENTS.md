# 日誌の保存・追記ルール

ユーザー指定（2026-10-26）：毎日の日誌は、このリポジトリの `main` ブランチの `diaries` 配下へ保存・追記する。

- 日付は日本時間（Asia/Tokyo）を基準にする。既存形式 `diaries/YYYY-MM-DD/diary_YYYYMMDD.md` を使う。
- 作業前に対象日の日誌の最新版を取得する。同じ日の日誌があれば内容を保持して、新しい実況・振り返りだけを追記する。なければ作成する。
- 実況、環境認識、売買、判断理由、反省・検証課題を日本語のMarkdownで整理する。ユーザーの訂正を反映し、口述の不明点は未確認として残す。
- 実取引、Paper Trading／デモ、未実行の検討案を区別する。約定履歴で確認した値と本人の申告・概算を区別し、不確かな数量や価格から確定損益を作らない。
- 日経225と個別銘柄のシンクロ、寄り付き回避、デルタ上サイン、「おかしい」時の即撤退、分割利確は、当日の記録がある範囲で整理する。
- 別の会話やローカルファイルを自動取得できるとはみなさない。実際に参照できた記録を使い、記録のない日の取引を作らない。
- 既存の日誌と照合して重複追記を避ける。原資料・CSV・画像は保持する。追記のために過去の日誌や別ファイルを削除・移動しない。
- GitHubへの保存が成功したことを確認してから、更新した日誌へのリンクを伝える。保存失敗を成功として報告しない。

## 日付フォルダはフラット

`diaries/YYYY-MM-DD/` の直下に Markdown、CSV、画像を置く。次のサブフォルダは作らない。

- `source-data/`
- `screenshots/`
- `assets/`
- `market_context/`
- `ny-source-data/`
- `ニューヨーク時間/`

マーケットコンテキストの出力は `market_context.md`、`JP225_market_context.png`、`US100_market_context.png` として同じ日付フォルダへ書く。別日のファイルは、ファイル名の日付が指す `diaries/YYYY-MM-DD/` へ置く。リポジトリ直下の日付フォルダや `assets/YYYY-MM-DD/` には置かない。`2026 Daily/`、`success_trade_quiz_20261003/`、`GOLD/`、`weekly_reports/`、`market_data/`、`scripts/`、`docs/`、サイト用HTMLは日付フォルダへ移さない。

## 収集データ・時系列の追加要件（2026-11-01）

- 日誌作成時には [JOURNAL_REQUIREMENTS.md](JOURNAL_REQUIREMENTS.md) と [データ取り込み手順書](requirements/TRADE_DIARY_DATA_IMPORT_PROCEDURE.md) を読み、松井証券CSV・TradingViewペーパートレード・日経平均／JP225・US100足・個別銘柄の板と歩み値・OneDriveの当日チャート画像を、実際に参照できる範囲で関連付ける。
- JP225 / US100 の足CSVは **Dukascopy（`market_data/dukascopy/`、`coverage.csv` で対象日確認）を主**、Axiory（`market_data/axiory/`）は当該日があるときだけの副とする。詳細は [market_context_recipe.md](market_context_recipe.md) と手順書の「JP225 / US100 足CSV」。使った参照先を日誌に明記し、無い日は未受領とする。
- 各取引について、9時台のビフォー、エントリー直前、エントリー10分後、前引け11:30、大引け15:30の5時点を記録する。各時点の終値には銘柄・時間足・足の時刻・確定状態・出典を付け、未取得の資料や価格は推測せず明記する。
- 新しい記録がない日は、テンプレートだけの空の日誌を作らず、変更なしとする。

## 日経平均の定型分析（2026-11-05追加）

本人が毎回分析・読み上げる固定項目は以下。日経平均の環境認識を整理するときは、この設定を共通テンプレートとして使う。

| 分析項目 | 設定・色 |
|---|---|
| 週足の移動平均 | 20 SMA・白色 |
| 日足の移動平均 | 20 SMA・赤色 |
| 60分足の移動平均 | 20 SMA・黄色 |
| 5分足の移動平均 | 60 EMA・緑色 |
| Open | 日本時間9:00の価格 |
| Williams %R | 60分足・期間15 |

- 各MAに対する価格の上下、MAの向き、％Rの向き・位置、9:00 Openとの位置関係は、当日の読み上げ・資料で確認できる範囲で記録する。
- 日経平均・先物・JP225 CFDは実際の銘柄・配信系列を明記し、9:00価格を別系列で代用しない。9:00 Openは終値とは区別する。
- 値・方向・位置関係が未提示なら未確認／未取得とし、固定設定だけから当日の分析結果や売買判断を推測しない。期間15は％Rの設定期間で、15分足という意味ではない。
- 詳細な記入欄は[JOURNAL_REQUIREMENTS.md](JOURNAL_REQUIREMENTS.md#日経平均の定型分析テンプレート)を参照。新しい当日記録がない日は、このテンプレートだけの日誌を作らない。

## 日経平均の分析を引き継ぐ運用（2026-11-05本人指定）
- 週足20SMAの環境認識は週1回の確認を基本とし、同じ週は直近の確認済み記録を引き継ぐ。日足20SMAは日1回の確認を基本とする。前日・前々日等の確認済み日誌を参照し、毎回「未確認」に戻さない。
- 引き継いだ項目には元の確認日・参照日誌と「引き継ぎ」を記し、当日に新規確認した結果と区別する。前の記録が確認できない場合は作らない。新しい読み上げや訂正があれば優先して更新する。
- 週足・日足の分析頻度は本人の確認ルーチンであり、進行中のMAが動かないという意味ではない。60分足20SMA、ボリンジャーバンドの拡大・縮小、5分足60EMA、9:00 Openとの上下、60分足Williams %R（15）は当日の実況に応じて更新する。
- 明確な訂正は追記欄だけでなく、日誌冒頭の定型分析表にも反映し、古い「未確認」や聞き取り保留と矛盾させない。売買記録・原資料は保持する。
- 11月5日の本人確認例：週足20SMA（白）レンジ、日足20SMA（赤）下、60分足20SMA（黄）横・レンジ、BB拡大、5分足60EMA（緑）横、9:00 Openより下、60分足%R（15）下。これは当日の分析であり、将来の日を固定する設定値ではない。
