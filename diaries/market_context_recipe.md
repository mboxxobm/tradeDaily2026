# US100 / JP225 日次マーケットコンテキストのレシピ

この手順は、日次トレード日誌へ指数CFDの複数時間足チャートと指標値を再現可能な形で追加するための仕様です。

## データ元と銘柄

- データ元はAxiory MetaTrader 5。取得銘柄は `JP225` と `US100`。
- 口座によって `JP225Cash` / `US100Cash` と表示される銘柄は別の価格配信系列です。今回の日誌コンテキストはAxiory系列に統一し、XM等の別口座の取引価格と混ぜません。
- 保存する足は `M1`, `M5`, `H1`, `D1`, `W1` のOHLC。CSVの `time_utc` は足の開始時刻を示すUTC時刻です。日誌・チャートの表示時刻はJSTへ変換します。
- `tick_volume` はその足の価格更新回数です。各ティックの時刻・価格を並べた生ティックデータではありません。今回の移動平均・W%R・ローソク足チャートに生ティックは不要です。
- 列: `time_utc`, `open`, `high`, `low`, `close`, `tick_volume`, `spread`, `real_volume`。

## 保存と更新

- `market_data/axiory/{銘柄}_{時間足}.csv` は初回取得からの累積マスターです。
- 平日更新時は最終時刻から2日分を重ねて再取得し、新しい足と修正足をUTC開始時刻で統合します。更新差分・実行ログは同フォルダのローカル補助フォルダへ保存します。
- 土曜日・日曜日は市場休場として、データ取得・日次日誌・チャート生成をスキップします。手動実行時もスクリプトがJSTの曜日を判定し、実行履歴に「スキップ」を記録します。
- 未確定足は指標・チャートに含めません。初回取得要求は2023-01-03 UTCからですが、実際に入手できる最古の日付は時間足ごとに異なります。M1/M5/H1の疎な代替データは日ごとの本数基準で除外します。
- MT5のCFDでは `real_volume` が0の場合があります。出来高やデルタ出来高の代用として `tick_volume` を扱わず、必要な分析ソースがない場合は「未取得」と記します。

## 指標の計算

すべて確定足の終値を使います。

- **M5 EMA60（緑）**: M5終値の60期間指数移動平均。`span=60`, `adjust=False`。
- **H1 / D1 / W1 SMA20**: 各時間足の終値を使う直近20本の単純移動平均。チャート色はH1=黄、D1=赤、W1=紫。
- **H1 Williams %R(15)**: 直近15本のH1高値・安値と確定終値から計算。`-100 × (15本最高値 − 終値) ÷ (15本最高値 − 15本最安値)`。
  - `値 <= -60`: 下側ゾーン
  - `-60 < 値 < -40`: 中立帯
  - `値 >= -40`: 上側ゾーン
  - 数値とゾーンの両方を表示し、境界値の扱いも上記の通り固定します。
- **パーフェクトオーダー（PO）**: H1・D1・W1を個別に判定。上昇POは `SMA5 > SMA20 > SMA60` かつ3本すべてが5本前より上。下降POは逆順で、3本すべてが5本前より下。それ以外は「なし」とします。ここでは日誌内で再現できるよう、このルールをPOの定義として固定します。

## 日次チャート仕様

銘柄ごとに1枚の多時間足PNGを作ります。縦に次の5パネルを並べます。各足は実際の日時順を保ちつつ、OHLCデータがない区間の実時間幅を使わず、固定の短い間隔に圧縮します。M5/H1/W%RにはJSTの日付切替線を引き、週末をまたぐ場合は前回取引の終了位置と月曜の最初の足（OPEN）を別の垂直線で示します。データのない足は作りません。

1. M5ローソク足（直近360本）+ EMA60（緑）
2. H1ローソク足（直近5取引日）+ SMA20（黄）
3. H1 W%R(15)（直近5取引日）+ -60 / -50 / -40の水平線（シアン）
4. D1ローソク足（直近90本）+ SMA20（赤）
5. W1ローソク足（直近78本）+ SMA20（紫）

ローソクは上昇=赤、下落=青。縦軸は指数ポイント、横軸はJSTです。H1とW%RはJST 09:00を取引日の区切りとし、直近5取引日を表示します。09:00より前の足は前営業日のセッションに含めるため、金曜セッションの土曜朝の終盤も表示されます。D1は直近90本、W1は直近78本を表示します。マスター履歴全体で指標を計算した後、表示範囲だけを切り出すため、表示範囲より前の足もSMA20とW%R(15)の計算に使われます。

## 日誌への追加

- 自動出力先: `diaries/YYYY-MM-DD/market_context/market_context.md` と、`JP225_market_context.png` / `US100_market_context.png`。
- 同日の日誌 `diary_YYYYMMDD.md` が存在する場合、スクリプトはマーカー付きのマーケットコンテキスト欄を追加または更新し、レポートへの相対リンクとPNGを埋め込みます。日誌本文がまだない場合も、独立レポートとチャートは作成します。取引対象が別口座のCash銘柄なら、Axioryの指標は「参考コンテキスト」と明記し、約定価格・損益の照合には使いません。
- このデータは価格の整理・表示用であり、売買推奨ではありません。

## 実行

Axiory MT5を起動・接続し、リポジトリのルートから実行します。

```powershell
& '..\mt5History\.venv-jp225\Scripts\python.exe' '.\scripts\update_market_context.py'
```

必要なPythonパッケージは `scripts/requirements-market-context.txt` に記載します。環境が異なる場合、`MT5_TERMINAL_EXE` と `MT5_EXPECTED_DATA_DIR` 環境変数で端末実行ファイルと接続先データフォルダを指定できます。

Windowsの平日タスクは月曜日から金曜日の07:20 JSTにローカルのMT5端末からデータを更新します。タスクはリポジトリの作業ツリーを更新しますが、GitHubへのcommit/pushは自動実行しません。GitHubの履歴を更新する場合は、変更されたマスターCSV・日誌レポート・チャートを確認してcommit/pushします。
