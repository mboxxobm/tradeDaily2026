# 板読み連動トレード復習クイズ

板読みToolsの実データと、日誌の取引履歴を突き合わせて作った復習用ページです。

## 収録内容

- 1ケースにつき3枚：9:00からENTRYまでのBEFOREチャート、ENTRY時点の板10段、答え合わせ用AFTERチャート
- ENTRY時点のVWAP、最良買い・最良売り、スプレッド、買い／売り上位5段の需給差
- 板読みの観察ポイント、キリ番、ダウ理論の確認欄
- 画像クリックで拡大表示

## 収録ケース

- B001：2026/08/28 任天堂（7974）09:15 ENTRY、+1,000円
- B002：2026/08/19 村田製作所（6981）09:14 ENTRY、+2,000円
- B003：2026/08/24 村田製作所（6981）09:43 ENTRY、+1,800円

## データの扱い

元の板読みToolsは約4.9GBあるため、GitHubには全量をコピーしていません。`data/` にクイズで使った銘柄・時刻の板10段と出典ファイル名だけを抜粋し、`assets/` に再現用のSVGチャートを保存しています。元データが必要な場合は、`source_manifest.json` の出典ファイルをローカルの板読みToolsから参照してください。

## 開き方

同じフォルダの `index.html` をブラウザで開いてください。回答後にAFTERが表示されます。
